# Lodestar for Mac

Signed and notarized builds of Lodestar, and the feed that installed copies check for updates.

**Download:** [Lodestar.dmg](https://github.com/arwin95/lodestar-releases/releases/latest/download/Lodestar.dmg) (always the newest version). Open it and drag Lodestar to Applications.

Lodestar updates itself: it checks once a day and installs a new version when you quit it. **Lodestar → Check for Updates…** checks right away.

Needs macOS 26 or later on an Apple silicon Mac.
